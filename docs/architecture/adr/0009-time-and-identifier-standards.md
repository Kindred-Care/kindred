# 0009. UTC, IANA time zones and UUIDv7

- Status: Accepted (implemented in Milestone 1)
- Date: 2026-10-17
- Source: Section 2 (time and identifiers approved), Section 4 keys and time

## Decision

- Instants are stored as `timestamptz` in UTC and modelled as `DateTimeOffset`. A `DateTime` property on
  an entity fails model building.
- IANA zone names are stored where local time matters (organizations, clients, shifts); display converts
  per organization and client.
- Primary keys are UUIDv7, generated by the application (`Identifiers.NewId()` uses
  `Guid.CreateVersion7()`), never by the database, so an ID exists before the row is written and sorts by
  creation time. Entities reject any other ID.
- The server-received time is authoritative; device-reported times are stored separately and never used
  for authorization or ordering.
